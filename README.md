# ☕ Telegram Tips Bot — сделай сам

Пошаговый гайд: как за **5 минут** собрать Telegram-бота, который принимает **чаевые в крипте** через Crypto Pay API.

Для кого этот README: **для новичков**. Если ты никогда не запускал Python — не страшно, всё расписано по шагам. Просто повторяй.

---

## 🎯 Что получится в итоге

Пользователь открывает твоего бота, видит кнопки:

```
💸 1 USDT   💸 3 USDT   💸 5 USDT
💸 10 USDT  💸 25 USDT
        ✏️ Своя сумма
```

Нажимает сумму → бот создаёт счёт в крипте → человек платит внутри Telegram → деньги приходят тебе в CryptoBot. Всё.

## 🪜 Шаг 1. Установи Python

1. Скачай Python с [python.org/downloads](https://www.python.org/downloads/) (версия **3.10 или выше**).
2. Запусти установщик.
3. **Самое важное:** на первом экране поставь галочку **✅ Add python.exe to PATH**.
4. Нажми **Install Now** → дождись → **Close**.

Проверка: нажми **Win + R**, введи `cmd`, Enter. В чёрном окне напиши:

```
python --version
```

Должно показать `Python 3.10.x` или новее. Если пишет «не является командой» — вернись к шагу 1, переустанови с галочкой.

---

## 🤖 Шаг 2. Создай Telegram-бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправь `/newbot`.
3. Введи **имя** бота (любое, например «Мои чаевые»).
4. Введи **username** — должен заканчиваться на `bot` (например `my_tips_bot`).
5. BotFather пришлёт **токен** вида:
   ```
   1234567890:MAYONEzik22038
   ```
6. **Скопируй и сохрани его** — это `BOT_TOKEN`. Никому не показывай.

---

## 💰 Шаг 3. Создай приложение Crypto Pay

1. Открой [@CryptoBot](https://t.me/CryptoBot) в Telegram.
2. Отправь `/start`, потом выбери **Crypto Pay**.
3. Нажми **Create App**.
4. Введи название приложения (любое, например «Мои чаевые»).
5. CryptoBot пришлёт **API Token** вида:
   ```
   123456:aabbVVGGDDYAAAA
   ```
6. **Скопируй и сохрани** — это `CRYPTO_PAY_TOKEN`.

> 💡 Хочешь сначала протестировать бесплатно? В @CryptoBot → Crypto Pay → My Apps есть **Testnet**. Там выдаются тестовые монеты, и можно отладить всё без реальных денег.

## 📁 Шаг 4. Скачай проект

Создай папку, например:

```
C:\Bots\TipsBot\
```

Внутри неё должны быть **три файла**. Их можно создать прямо в Блокноте.

### 📄 `bot.py`

Полный код бота — смотри файл `bot.py` в этом репозитории. Скопируй его целиком в Блокнот и сохрани как `bot.py` (в поле «Тип файла» выбери **Все файлы**, кодировка — **UTF-8**).

### 📄 `requirements.txt`

```
aiogram==3.13.1
aiohttp
python-dotenv
```

### 📄 `.env`

```
BOT_TOKEN=сюда_вставь_токен_от_BotFather
CRYPTO_PAY_TOKEN=сюда_вставь_токен_от_CryptoBot
```

Пример:

```
BOT_TOKEN=1234567890:AAHodUYWnSdLUftv2PQ9uBwfq025KKmsEEs
CRYPTO_PAY_TOKEN=650483:AAHodUYWnSdLUftv2PQ9uBwfq025KKmsEEs
```

> ⚠️ Никаких кавычек, пробелов вокруг `=`, переносов строк внутри значений.

## 📦 Шаг 5. Установи зависимости

Открой **cmd прямо в папке проекта**:

1. Открой папку `C:\Bots\TipsBot\` в Проводнике.
2. Кликни в **адресную строку** сверху, введи `cmd`, нажми Enter.
3. Откроется чёрное окно уже в нужной папке.

Выполни:

```
pip install -r requirements.txt
```

Жди минуту. В конце увидишь что-то вроде `Successfully installed aiogram-3.13.1 aiohttp-3.9...`.

## 🚀 Шаг 6. Запусти бота

В том же окне cmd:

```
python bot.py
```

Если всё правильно, увидишь:

```
✅ Crypto Pay: @YourApp (app_id=650483)
✅ Telegram-бот: @your_bot
🚀 Бот запущен
```

**Окно не закрывай** — пока оно открыто, бот работает. Чтобы остановить — `Ctrl+C`.

## ✅ Шаг 7. Проверь в Telegram

1. Открой своего бота по ссылке `https://t.me/твой_бот`.
2. Нажми **Start** или отправь `/start`.
3. Должны появиться кнопки с суммами.
4. Нажми **💸 1 USDT** → **🚀 Оплатить** → оплати.
5. Вернись и нажми **✅ Проверить оплату**.
6. Бот ответит: `✅ Оплата получена! Спасибо за 1 USDT 🙏`.

Деньги придут на твой баланс в @CryptoBot.

## 🖱️ Хочу запускать в один клик (Windows)

Создай файл `start.bat` в папке проекта:

```bat
@echo off
cd /d "%~dp0"
python bot.py
pause
```

Теперь двойной клик по `start.bat` — бот запускается.

## ⚙️ Как настроить под себя

Всё в начале `bot.py`:

| Что менять | Зачем |
|---|---|
| `ASSET = "USDT"` | Валюта приёма: `USDT`, `TON`, `BTC`, `ETH`, `TRX`, `USDC` |
| `TIP_AMOUNTS = [1, 3, 5, 10, 25]` | Суммы на кнопках |
| `TEXT_START`, `TEXT_THANKS` | Тексты приветствия и благодарности |

## 🧪 Хочу протестировать без реальных денег

В `bot.py` замени:

```python
CRYPTO_PAY_API = "https://testnet-pay.crypt.bot/api"
```

И возьми **тестовый** токен в @CryptoBot → Crypto Pay → My Apps → **Testnet**. Тестовые монеты ничего не стоят.

## 🛠️ Частые проблемы

| Что видишь | Что случилось | Что делать |
|---|---|---|
| `'python' не является внутренней командой` | Python не в PATH | Переустанови с галочкой **Add to PATH** |
| `ModuleNotFoundError: No module named 'aiogram'` | Зависимости не установлены | Запусти `pip install -r requirements.txt` в папке проекта |
| `❌ Telegram: ... 401 Unauthorized` | Токен бота неправильный | Скопируй токен заново из @BotFather |
| `❌ Crypto Pay: ...` | Токен Crypto Pay неправильный | Проверь в @CryptoBot → Crypto Pay → My Apps |
| `TypeError: unsupported operand type(s) for \|` | Python старше 3.10 | Поставь Python 3.10+ или замени `dict \| None` на `Optional[dict]` |
| `asset is not supported` | Валюта недоступна | Поменяй `ASSET` на `USDT` |
| `start.bat` мгновенно закрывается | Неверная кодировка файла | Сохрани в ANSI или вообще запусти через cmd вручную |
| Окно cmd висит и ничего не делает | Это нормально — бот работает | Не закрывай окно, иди в Telegram |

## 🔒 Безопасность — прочитай обязательно

1. **Никогда не выкладывай `.env`** в интернет, GitHub, чаты, скриншоты.
2. **Не вставляй токены в код** — храни только в `.env`.
3. Если токен случайно утёк:
   - Telegram → @BotFather → `/mybots` → бот → **API Token → Revoke**.
   - Crypto Pay → @CryptoBot → Crypto Pay → My Apps → **Revoke**.
4. Создай заново и замени в `.env`.

## 📜 Как это работает (для любопытных)

```
Пользователь → /start
       ↓
Бот показывает кнопки с суммами
       ↓
Пользователь нажимает «3 USDT»
       ↓
Бот → Crypto Pay API → createInvoice(asset=USDT, amount=3)
       ↓
Crypto Pay возвращает bot_invoice_url
       ↓
Бот показывает кнопку «🚀 Оплатить» со ссылкой
       ↓
Пользователь платит внутри Telegram
       ↓
Пользователь нажимает «✅ Проверить оплату»
       ↓
Бот → Crypto Pay API → getInvoices(id)
       ↓
status == "paid" → бот благодарит
```

Используются методы Crypto Pay API:
- `getMe` — проверка токена при старте
- `createInvoice` — создание счёта
- `getInvoices` — проверка статуса

Документация: [help.crypt.bot/crypto-pay-api](https://help.crypt.bot/crypto-pay-api)
